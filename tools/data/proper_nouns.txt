# 人工維護的專有名詞黑名單（補 ECDICT 標註的漏網之魚）
#
# 什麼時候該加進來：
#   字典把它當**普通名詞**（所以歌詞裡小寫、或出現在句首時不會被
#   `LyricCasing.looksProper` 抓到），但實際上在歌詞裡幾乎只當名字用。
#
# 什麼時候**不該**加：
#   它同時是常用字（rose / sky / grace / hope）。那些字被挖空是合理的，
#   加進來只會讓題目變少。
#
# 格式：一行一個字，小寫；`#` 之後是註解。詞形變化不必列——比對用的是
# 字典原形（`vega` 一條就夠）。
#
# 大部分專有名詞已經由 `build_assets.py` 的兩層自動判定處理：
#   1. ECDICT 只有大寫形式（`California`）—— 約 2,000 個
#   2. 中文釋義的括號標註（`艾比（女子名）`）—— 約 2,569 個
# 這份清單只補「兩層都沒抓到、但擁有者實際在歌詞裡看到」的字。

# 擁有者回報：歌詞裡是名字，字典卻當普通名詞
