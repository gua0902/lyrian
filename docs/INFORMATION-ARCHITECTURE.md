## 0. 一句話流程

> 選一首歌 → 選一種練法 → 練習 → 錯的字自動進字庫 → 複習 → 回饋下次選歌

## C. 每個頁面的內容階層

### C1. 搜尋頁

```
標題區      Lyrian 🎵
輸入區      歌手名稱（icon: person）
            歌曲名稱（icon: music.note）
            [🔍 搜尋]  ← 紫色藥丸
結果區      找到你的下一首            2 首歌曲
            ┌─ 歌曲卡片 ────────────────┐
            │ [封面64]  歌名            ▶│
            │           歌手 · 難度 · 時長│
            │           填空數 · 主題     │
```

| 元素 | 來源 | 現況 |
|---|---|---|
| 封面 | iTunes `artworkUrl100` → 600x600 | ✅ |
| 歌名 / 歌手 | LRCLIB | ✅ |
| 時長 | LRCLIB `duration` | ✅ |
| 填空數 | 計算（上限 10） | ✅ |
| 難度 | **ECDICT 詞頻** | ❌ |
| 主題（生活英語） | **無來源** | ❌ |

## G. 資料流（一個單字的一生）

```
練習答錯 "Hope"
      ↓
features/practice/vocabCandidate.ts
  vocabCandidateFromAttempt()
  → { lemma: 'hope', surfaceForm: 'Hope',
      contextLine: 'I keep a little hope inside my heart',
      songId: 123 }
      ↓
db/repositories/practiceLog.ts
  logPracticeAnswer()  ← 單一交易
      ├─ saveSong()          快取歌曲
      ├─ saveLyricLines()    快取歌詞
      ├─ addVocabFromError() ★ 字庫（lemma 去重）
      ├─ recordAttempt()     作答紀錄
      └─ bumpDailyStat()     每日統計
      ↓
vocab 表
  lemma='hope' error_count=1 status='learning'
  context_line='I keep a little hope inside my heart'
      ↓
字庫 Tab 讀 listVocab()
      ↓
顯示卡片：Hope / 希望 / 歌詞原句 / 歌名 / 錯誤 N 次
```

## J. 需要你裁決的 8 件事

| # | 問題 | 我的建議 | 為什麼 |
|---|---|---|---|
| 1 | **ECDICT 要不要接** | 要 | 一次解掉中文釋義、難度、詞頻選字。**但卡在授權未確認** |
| 2 | **離線能不能練已快取的歌** | 能 | 目前是洞。捷運上沒訊號就完全不能用 |
| 3 | **「生活英語」主題怎麼來** | 自訂分類表（用 ECDICT 詞頻 + 主題標籤） | LRCLIB 與 iTunes 都沒有 |
| 4 | **字庫複習的入口** | 字庫頁頂部「開始複習」按鈕 | 比「點單字」清楚 |
| 5 | **單字卡顯示什麼** | 單字／音標／中文／歌詞原句／詞頻 | 手勢長按觸發 |
| 6 | **要不要做平板/橫向** | 先不做 | MD3 稽核 Layout 目前 5/10，但手機優先 |
| 7 | **深層連結要不要做** | 先不做 | 沒有分享需求前沒價值 |
| 8 | **「錯誤 Love」顯示什麼** | 顯示選錯的字（需要 join attempt） | 參考圖是這樣，比次數更有用 |
